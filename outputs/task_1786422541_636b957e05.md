# Redis 核心用途（80字内详述）

## 高性能内存数据存储  
Redis 是基于内存的键值数据库，QPS 可达约 100,000，支持毫秒级响应 [2]。  

### 多场景核心用途  
用作缓存、计数器、分布式锁（String）；消息队列与时间轴（List）；用户信息存储（Hash）；去重与共
