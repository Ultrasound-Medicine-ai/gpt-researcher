# Redis 全面技术报告（2026年版）

## 核心定义与架构特性

Redis（Remote Dictionary Server）是一个开源、遵循 BSD 协议的内存中 NoSQL 键值存储系统，广泛用作数据库、缓存和消息代理 [2][6][8]。其核心设计是将全部数据驻留在内存中，从而实现极低延迟与超高吞吐——实测读性能达 110,000 次/秒，写性能达 81,000 次/秒 [chunk_id=621d5033...]。尽管采用单线程事件驱动模型，Redis 通过高效 I/O 多路复用（如 epoll/kqueue）确保高并发下的稳定响应 [chunk_id=621d5033...]。

Redis 支持丰富的原生数据结构：字符串（String）、哈希（Hash）、列表（List）、集合（Set）、有序集合（Sorted Set）、HyperLogLog、GEO、Stream 等 [7][chunk_id=621d5033...]，远超传统键值存储能力，使其可直接支撑排行榜、实时计数、地理围栏、消息队列等复杂场景 [4][chunk_id=621d5033...]。

## 关键技术能力

### 原子性与事务支持  
所有 Redis 命令均为原子操作，保障高并发下数据一致性；同时提供 MULTI/EXEC 事务机制及 Lua 脚本支持，允许在服务端执行多步逻辑，避免网络往返开销 [chunk_id=621d5033...]。

### 持久化与可靠性  
Redis 提供两种持久化方式：RDB（快照）与 AOF（追加日志），支持异步或同步刷盘策略，兼顾性能与数据安全性 [6][chunk_id=621d5033...]。主从复制（Master-Slave）与哨兵（Sentinel）机制构成基础高可用方案，而 Redis Cluster 则提供原生分片与自动故障转移能力 [chunk_id=621d5033...]。

### 高级功能生态  
内置发布/订阅（Pub/Sub）、键过期（TTL）、通知（Keyspace Notifications）、连接池管理、管道（Pipeline）批量操作等特性，显著扩展其在实时通信、会话管理、限流熔断等场景的应用深度 [chunk_id=621d5033...][2]。
