# Redis与Memcached差异及选型

## 核心差异
| 维度 | Redis | Memcached |
|---|---|---|
| 结构 | 丰富(Hash等)[2] | 仅KV[4] |
| 架构 | 单线程[1] | 多线程[12] |
| 持久化 | RDB/AOF[5] | 无[5] |
| 集群 | 原生[3] | 客户端分片[3] |
| 许可 | AGPLv3[12] | BSD[12] |

## 性能分析
Memcached凭多线程在简单KV读写占优，2026年测试其写吞吐量较Redis高33%[12]。Redis在复杂场景内存利用率更优[13]，且支持持久化与原生集群，Memcached纯内存且依赖客户端分片[3]。

## 选型建议
需复杂数据、持久化或消息队列选Redis[5]。仅需高并发简单KV且需规避AGPLv3许可限制选Memcached[12]。
