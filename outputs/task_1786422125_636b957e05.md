# Redis 核心用途（80字内精要报告）

## 高性能内存数据服务  
Redis 是开源、基于内存的 NoSQL 键值数据库，主打亚毫秒级读写延迟，专为缓存、消息队列、分布式锁、实时分析及地理空间服务等场景设计[3][4][5]。它支持 String、Hash、List、Set、ZSet 等
