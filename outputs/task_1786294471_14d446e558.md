# Redis 技术概述
## 核心定位与性能
Redis（Remote Dictionary Server）是一款开源的高性能内存键值存储系统，广泛用作数据库、缓存及消息代理[7]。其数据全驻留内存，读写延迟达微秒级，单机可稳定支撑超10万QPS[11]。
## 数据结构与架构优势
除基础字符串外，Redis原生支持哈希、列表、集合、有序集合、流等9种复杂数据类型[11]。凭借RDB/AOF混合持久化、哨兵自动故障转移及全原子操作，它已成为热点缓存、分布式锁、实时排行榜与高并发消息队列的首选基础设施[3]。
