# Redis 核心用途详解

## 高性能内存数据存储  
Redis 是开源、基于内存的 NoSQL 键值数据库，专为亚毫秒级响应设计，所有数据驻留主内存而非磁盘或 SSD，实现极致读写速度 [3][4]。其核心用途涵盖四大高价值场景
