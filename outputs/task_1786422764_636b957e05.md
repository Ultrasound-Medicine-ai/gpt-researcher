# Redis 核心用途（80字内精要报告）

## 核心定位与架构特性  
Redis 是开源、内存型 NoSQL 键值数据库，以极低延迟提供读写性能，核心用途为高速缓存、会话存储、消息队列及实时数据结构操作 [3][4][5]。其数据全驻 RAM，避免磁盘 I/O
