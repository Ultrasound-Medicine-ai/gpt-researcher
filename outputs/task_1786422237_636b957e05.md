# Redis 核心用途详解（80字内）

## 高性能内存键值存储  
Redis 是开源、基于内存的 NoSQL 键值数据库，提供亚毫秒级延迟，主要用作应用缓存、会话管理、消息队列及实时数据处理 [3][4][5]。其核心价值在于通过 RAM 存储加速
