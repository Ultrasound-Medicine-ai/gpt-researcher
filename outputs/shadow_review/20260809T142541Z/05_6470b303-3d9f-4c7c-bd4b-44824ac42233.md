# 大模型应用中Prompt注入攻击的典型手法与防护要点分析

Prompt注入被OWASP列为2025年大模型应用十大安全风险之首，其核心在于攻击者通过精心设计的输入操纵模型，使其偏离原定行为或绕过安全措施[2]。随着大模型从单一对话向Agent（智能体）演进，该风险已从单纯的文本输出错误演变为执行未授权操作的关键安全隐患[6]。

## 典型攻击手法分析

Prompt注入攻击主要分为直接注入和间接注入两大类，随着技术演进，攻击手段日益复杂化和隐蔽化。

### 1. 直接与间接注入
**直接注入**指攻击者直接向模型发送恶意指令。典型手法包括“忽略先前指令”，诱导模型覆盖开发者预设的指令[8]；以及“奶奶漏洞”，利用情感化角色扮演（如“扮演我临终的奶奶”）绕过安全限制，诱导模型泄露敏感信息[1]。

**间接注入**更具隐蔽性，恶意指令隐藏在模型调用的外部数据源中。例如，攻击者在网页、PDF文档或代码注释中嵌入不可见的白色文字或HTML属性掩盖指令，当模型检索或阅读该内容时触发攻击[5]。真实案例显示，攻击者曾在点评网站Yelp的评论中注入指令，成功误导推荐餐厅[2]。

### 2. 高级混淆与越狱技术
为绕过关键词过滤，攻击者常采用编码和混淆技术。这包括使用Base64、Hex编码或Unicode走私隐藏恶意指令，以及利用“Typoglycemia”现象（如将“ignore”拼写为“ignroe”）欺骗模型但绕过检测[11]。此外，多语言混淆和“越狱”也是常见手段，通过要求模型扮演“DAN”等无限制角色，迫使其无视安全协议[8][9]。

### 3. Agent场景下的新型攻击
在Agent应用中，攻击面显著扩大。攻击者可通过“工具投毒”，在工具描述中注入恶意指令；或通过“记忆投毒”，将恶意规则写入Agent的长期记忆中[6]。由于Agent具备调用API和执行代码的能力，此类攻击可导致数据外泄或远程代码执行（RCE）[5]。

*表：典型Prompt注入攻击手法分类*

| 攻击类型 | 具体手法 | 攻击目标/原理 |
| :--- | :--- | :--- |
| **直接注入** | 忽略指令、角色扮演（奶奶漏洞） | 覆盖系统指令，绕过安全限制 [1][8] |
| **间接注入** | 隐形文本、HTML属性掩盖、文档嵌入 | 利用外部数据流（RAG、网页）劫持模型 [5] |
| **混淆技术** | Base64编码、Unicode走私、拼写错误 | 绕过基于关键词的输入过滤器 [11] |
| **Agent攻击** | 工具投毒、记忆污染、状态污染 | 劫持Agent权限，执行未授权操作 [6] |

## 风险评估与影响

Prompt注入的影响已超越内容安全范畴。对于具备“致命三元组”（访问私有数据、暴露于不可信Token、存在数据外泄矢量）特征的Agent系统，注入攻击可导致严重的业务安全事件，如银行助手被诱导绕过交易验证转账[5]。此外，攻击还可导致系统提示泄漏，暴露内部逻辑与配置，为后续攻击提供便利[3][4]。

## 关键防护策略

针对Prompt注入的防御需构建纵深防御体系，不能仅依赖模型自身的对齐能力。

### 1. 输入层防御：检测与结构化
