# Redis 核心用途（80字精要报告）

## 高性能内存数据服务  
Redis 是面向实时数据应用的最快、功能最丰富的内存键值数据库，核心用途涵盖：缓存加速（支持多策略驱逐与字段级过期）；分布式会话存储；原生五大数据结构
