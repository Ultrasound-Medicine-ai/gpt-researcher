# Redis 核心用途（80字详述）

## 高性能内存数据服务  
Redis 是开源、ANSI C 编写的**内存型键值数据库**，支持字符串、哈希、列表、集合、有序集合等5+核心数据结构[6][3]；兼具**缓存、会话存储、消息队列、计数器、排行榜、实时统计**等
